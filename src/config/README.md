# src/config — розібрані пакети конфігурацій

Пакет конфігурації — `*.zip` зі знімком сутностей об'єкта конфігурації (`CNFOBJ`): рядки таблиць заголовків,
пов'язаних таблиць і перекладів плюс `ExportDetails.txt` (середовище, час створення, список таблиць)
(help, doc_id=132708). Докладно — `docs/ARCHITECTURE.md` §6.

## Розкладка

```
src/config/<доробка>/<дата формування>_<комплект>/
  ExportDetails.txt            як у пакеті
  <вміст архіву, розпакований>
  PACKAGE.md                   опис пакета для PREDPROD/PROD: що й як тестувати (help, doc_id=132733)
```

Сам zip у git не кладеться: він відтворюється з комплекту, а розпакований вміст дає читабельний diff.

## Стан

Формат рядків усередині архіву невідомий (Q-03). Перший крок пілота — вивантажити один пакет із тестового
комплекту, розкласти тут і описати формат у `docs/ARCHITECTURE.md` §6.1. Доти пакети формує й проводить людина
в інтерфейсі.
