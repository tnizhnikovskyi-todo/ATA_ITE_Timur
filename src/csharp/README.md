# src/csharp — C#-код доробок

Копія користувацького коду, внесеного в базу ITE. Оригінал — поле бізнес-логіки (`BL`) сутності в БД; сервер
додатків компілює його сам (`docs/ARCHITECTURE.md` §5.2). Розбіжність файлу з базою — дефект (A-02).

## Розкладка

```
src/csharp/<доробка>/
  rrt/<код методу>.cs          RRT-методи (один файл — один метод)
  lib/<бібліотека>/*.cs        бібліотеки коду C#
  ui/<код інтерфейсу>.cs       бізнес-логіка інтерфейсів, курсорів, довідників
```

## Заголовок файлу

Кожен файл починається з коментаря, за яким його знаходять у базі:

```csharp
// ITE: RRT-метод _TDINVCHK — Перевірка інвентаризації
// Об'єкт: DMZ · Подія: ANYCALL · Джерело: AFTERPOST · Тип процесу: <KDMT>
// Таблиця: RRT · Поле: BL · Збірки користувача: _TDLIB
// Специфікація: docs/modules/<доробка>/SPEC.md RM-01
```

Поля таблиці `RRT` поки невідомі (Q-05), тому рядок «Таблиця · Поле» для RRT-методів — ПРИПУЩЕННЯ.

## Збірка (тип перевірки BLD)

Бібліотеки платформи беруться з `%TEMP%\ITAsseblies\<версія>` на машині розробника (help, doc_id=133587) і в
git не кладуться. `.csproj` посилається на них через властивість `ItAssembliesDir`, яку задає розробник.
Заготовку проєкту, яку генерує кнопка «Редагувати у Visual Studio», зберегти тут при першій нагоді (Q-04).
